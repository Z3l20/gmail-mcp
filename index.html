Gmail MCP (personal)

A single-user, self-hosted tool for reading my own Gmail accounts.

What this application does

Gmail MCP is a personal, self-hosted server that lets an AI assistant read and summarise messages across the Gmail accounts belonging to its operator. It runs locally on the operator's own computer. It is not a product, not distributed, and has no users other than its operator.

How it works

  • Runs as a local process on the operator's machine and listens only on localhost.
  • Authenticates to Gmail with Google OAuth 2.0. Tokens are stored locally on that machine.
  • Reads message metadata and content on request in order to search and summarise it.
  • Sends no data to any third party. There is no hosted backend and no analytics.

Google account data used

The application requests the gmail.readonly scope. Read-only access is sufficient for its purpose; it does not send, modify, or delete mail.
