Frames Manila tools

Private, self-hosted tools for running one small business.

What this application does

Frames Manila tools are scripts and a local server that the owner of Frames Manila runs on his own computer. They read the shop's order log in Google Sheets and the shop's own Gmail inbox, so that the owner and the AI assistants he uses can look up orders and correspondence. It is not a product, is not distributed, and has no users other than the owner and his own shop account.

How it works

  • Runs as local processes on the owner's computer. The Gmail server listens only on localhost.
  • Signs in to Google with OAuth 2.0. Tokens are stored on that computer, readable only by the owner's user account.
  • Reads data on request. There is no hosted backend, no analytics and no telemetry.

Google account data used

  • gmail.readonly: read the shop's mail. It cannot send, change or delete anything.
  • spreadsheets.readonly: read the order log spreadsheet.
  • drive.file: create and edit only files this application created.
