Gmail MCP (personal)

A single-user, self-hosted tool for reading my own Google account.

What this application does

Gmail MCP is a personal, self-hosted server that lets AI assistants on its operator's own computers read and summarise the operator's Gmail, and work with the operator's Google Drive and Calendar. It is not a product, not distributed, and has no users other than its operator.

How it works

  • Runs as local processes on the operator's machines and listens only on localhost.
  • Authenticates with Google OAuth 2.0. Tokens are stored locally on those machines.
  • Reads data on request in order to search and summarise it.
  • Data an AI assistant reads goes to the AI model provider that runs it, to answer the operator's request. There is no hosted backend and no analytics.

Google account data used

  • gmail.readonly: read mail. It cannot send, change or delete anything.
  • drive, drive.readonly and drive.file, through a separate client: read and edit Drive files.
  • calendar, calendar.events and calendar.readonly, through the same separate client: read and edit calendars.
