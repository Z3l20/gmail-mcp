Privacy Policy

Frames Manila tools, last updated 9 October 2026

Scope of this policy

Frames Manila tools is a self-hosted application operated by the owner of Frames Manila for his own Google account and the shop's Google account. It is not offered to the public and has no other users.

Google user data accessed

The application requests these Google OAuth scopes:

  • https://www.googleapis.com/auth/gmail.readonly: read-only access to Gmail messages, threads, labels and settings. The application cannot send, modify or delete mail.
  • https://www.googleapis.com/auth/spreadsheets.readonly: read-only access to spreadsheets.
  • https://www.googleapis.com/auth/drive.file: access only to files the application itself creates.

How the data is used

Mail and spreadsheet data are read on demand so that the operator can look up and summarise the shop's own orders and correspondence.

Storage and retention

OAuth tokens are stored on the operator's own computer, readable only by the operator's user account. Revoking access at myaccount.google.com/permissions and deleting the local token files removes all access.

Sharing and transfer

When the operator asks an AI assistant about the shop's mail or orders, the data that assistant reads is sent to the AI model provider that runs it, such as Anthropic, to answer that request. Google user data is not sold, not used for advertising, and not otherwise transferred. There is no hosted backend, no analytics and no telemetry.

Limited Use disclosure

This application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
