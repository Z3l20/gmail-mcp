Privacy Policy

Gmail MCP (personal) — last updated 2 September 2026

Scope of this policy

Gmail MCP (personal) is a self-hosted application operated by a single individual for their own Google accounts. It is not offered to the public and has no users other than its operator.

Google user data accessed

The application requests the following Google OAuth scope:

  • https://www.googleapis.com/auth/gmail.readonly — read-only access to Gmail messages, threads, labels and settings.

This scope permits reading mail only. The application cannot send, modify or delete messages.

How the data is used

Message content and metadata are read on demand so that the operator can search, triage and summarise their own inboxes. Data is processed transiently to answer the operator's request.

Storage and retention

OAuth tokens are stored on the operator's own computer in a directory readable only by the operator's user account (file mode 0600). No message content is stored in any database. Revoking access at myaccount.google.com/permissions and deleting the local token files removes all access.

Sharing and transfer

Google user data is not sold, transferred or disclosed to any third party. There is no hosted backend, no analytics and no telemetry. Data does not leave the operator's machine except in requests to Google's own APIs.

Limited Use disclosure

This application's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
